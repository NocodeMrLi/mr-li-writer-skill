# 检索与事实验证规范

## 检索策略

1. **关键词组设计**：围绕主题拆出 3-5 个角度，每个角度一组关键词。
   - 示例：主题"2026 下半年软考报名"→ 角度 = [报名时间与入口, 科目变化, 报名条件, 通过率数据, 政策调整]
   - 中文为主；涉及国际数据或英文原始报告时补充英文关键词
   - 使用 WebSearch 的 query_keyword_groups 一次性覆盖多角度，不要逐个角度单独搜

2. **时效性判断**：
   - 以当前日期为锚点，搜索词中带上年份（如 2026）
   - 政策、报名时间、考试安排类信息必须使用最近 6 个月内的来源
   - 数据报告类优先引用最新一期，注明发布年份

3. **来源优先级**（从高到低）：
   - 官方机构公告、政府网站、考试主办方官网
   - 权威媒体报道、行业研究机构报告
   - 垂类媒体、专业社区讨论（仅用于舆情判断，不作事实依据）
   - 公众号/自媒体文章（仅作观点参考，需二次验证）

## 素材适配性自分析（闸口，必须执行）

搜到资料后，**先自己过一遍"这条能不能用"**，再决定采纳。不要无脑堆砌。

**星级溯源标准**（参考业界做法，内部使用）：

| 星级 | 来源类型 | 处理方式 |
|------|----------|----------|
| ⭐⭐⭐⭐⭐ | 政府文件、官方统计/财报、一手新闻报道、权威研究报告 | 直接采用 |
| ⭐⭐⭐⭐ | 专业机构分析、行业垂直媒体 | 可采用，关键数字仍建议二源印证 |
| ⭐⭐⭐ | 主流商业媒体、一手访谈引述 | 可作背景，不宜单独支撑关键结论 |
| ⭐⭐ | 二手汇总、个人博客、观点型自媒体 | 谨慎，仅作角度启发 |
| ⭐ | 无法溯源 / 孤证 / 情绪化标题党 | **直接丢弃，不写入** |

**自分析三步**：
1. 对每条候选资料打分（上表），低于 ⭐⭐ 或无法溯源的一律淘汰
2. 判断"适不适合本次任务"：与主题/读者/角度是否相关？数据是否过时？是否夹带广告？不合适的剔除
3. **若通过筛选的可信资料不足以支撑一个论点，立刻重新检索**（换关键词、换角度、换时间窗口），不得用低质资料硬凑

## 交叉验证规则

- 关键事实（数字、日期、政策条款、价格）**必须至少 2 个独立来源一致**才可写入正文
- 两个来源冲突时：优先信官方来源；仍无法确定则在文中如实说明存在分歧，或舍弃该事实
- 单一来源且无法验证的"惊人数据"（如"通过率高达 90%"）一律不用

## 去个人 IP / 人名（红线，写入前必查）

参考素材里常常夹带 KOL、博主、机构个人的名字（个人 IP）。**写正文时一律不得出现**：

- 不写任何人名、博主名、网红名、个人品牌名
- 引用观点时改为类别指代："某机构报告""业内人士""一位从业者表示""行业调研显示"
- 提取种子文档（extract_seed.py）或读检索结果时，若原文含人名，转写时主动抹掉，只保留观点与事实
- 例外：用户明确要求引用且属于公开新闻主体的公众人物（如政策发布者），仍须用户确认后才可写

## 软文与广告识别

以下来源内容需要警惕并剔除：
- 通篇推荐某机构/课程/工具的文章
- 带有明显转化话术（"扫码领取""回复关键词""限时优惠"）的内容
- 无署名、无数据出处、情绪煽动为主的自媒体文章

## 文末引用说明（必须带 URL）

**凡是正文用到的数据、政策、关键事实，必须在文章结尾设"参考资料"段**，逐条列出：

```
## 参考资料
1. 中国互联网络信息中心（CNNIC）第57次《中国互联网络发展状况统计报告》，2026-03 发布，数据截至 2025-12，https://www.cnnic.net.cn/...
2. 智联招聘《职场"人机共生"演进情况调研报告》，2025-09，样本 3112 份，https://www.zhaopin.com/...
3. 人民日报相关报道，2026-03-03，http://paper.people.com.cn/...
```

规范：
- **必须带原始 URL**，让读者能点回去验证；网页被墙或链接可能失效时，保留 URL 并注明"以官方最新页面为准"
- 写清机构/媒体 + 报告名 + 发布时间 + 数据时点
- 只列**实际用到**的来源，没用到的不凑数
- 引用的机构名用官方正式名称，不缩写误导
- 政府公告类 URL 直接放政府门户网站原始通知地址

## 检索记录（内部）

写作前在内部整理一份事实清单（不必展示给用户，除非用户要求）：

| 事实 | 来源 | 日期 | URL | 星级 | 是否采用 |
|------|------|------|-----|------|----------|
| ... | ... | ... | ... | ⭐⭐⭐⭐ | 是 |
| ... | ... | ... | ... | ⭐ | 否（无法溯源） |

正文中引用事实时，用自然方式带出来源类别和时间，如"根据 2026 年 3 月发布的官方统计"。**禁止写出具体品牌名、人名、网址链接堆砌在正文**（文末参考资料段除外）。

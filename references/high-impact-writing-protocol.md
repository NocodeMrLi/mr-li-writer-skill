# 高完成度文章增强规范

## 目标

本规范不是为了把文章写成“获奖作文”或文学作品，而是借高完成度文章的视角，让平台文章更有力量、更有记忆点、更不平庸。

一篇有力的文章不只要正确、自然、资料充足，还要有清楚的精神内核、能被记住的表达、合适的结构推进、克制但有余味的结尾。但它仍然首先是一篇给普通读者看的平台文章，必须清楚、好读、可转述、不过度文学化。

## 零、边界

高完成度不等于文学化。任何增强都不能牺牲普通读者的阅读意愿。

禁止把平台文章写成：

- 散文腔：意象很多，问题和判断很少。
- 文学炫技：句子漂亮，但读者看不出要说什么。
- 过度含蓄：为了余味不把关键判断说清楚。
- 情绪雾化：全是氛围、感受和隐喻，缺少具体动作。
- 宏大抒情：小问题突然升到时代、命运、人类等大词。
- 难以转述：读者读完觉得“好像很美”，但说不出核心意思。

增强后的文章必须通过三问：

1. 普通目标读者能不能读懂？
2. 读者能不能说出这篇文章的核心判断？
3. 读者能不能带走一个具体动作、判断、画面或提醒？

## 一、启动条件

以下情况必须执行本规范：

- 用户要求文章更有深度、力量感、完成度、记忆点、传播力或高级感。
- 文章用于公众号、知乎、征文、品牌内容、个人 IP、深度长文或重要发布。
- 选题本身有情绪、价值判断、关系、人生经验、行业观察或社会议题。

如果用户只是要短说明、通知、FAQ、商品参数或纯工具文，可以轻量执行，只保留“反平庸检查”。

## 二、主题升维

正式大纲前，先把选题从表层问题向深层问题推进一层，但不能拔高成口号，也不能升维到普通读者不关心的抽象高度。

| 表层 | 升维方向 |
|---|---|
| 事件 | 它暴露了什么关系、选择或代价？ |
| 方法 | 它背后真正要解决的心理或处境是什么？ |
| 经验 | 它能否说明一种长期规律？ |
| 情绪 | 情绪背后未被说出的需求是什么？ |
| 热点 | 热点之外，谁正在承担后果？ |
| 产品/工具 | 它改变的是效率、判断，还是人与工作的关系？ |
| 关系/生活 | 表面建议背后，人与人如何重新看见彼此？ |

示例：

```text
普通方向：夫妻之间的保鲜剂是沟通、仪式感和陪伴。
升维方向：长期关系里，真正稀缺的不是新鲜感，而是愿意反复把对方当成仍然值得认识的人。
```

## 三、记忆点设计

每篇文章至少设计一个“记忆钉子”。记忆点不是金句堆砌，而是读者读完后能带走的东西。

可选类型：

- 一个核心判断：能概括全文，但不空泛。
- 一个具体意象：物件、动作、场景或反复出现的小细节。
- 一个反常表达：看起来反常，但正文能支撑。
- 一个回环结构：结尾回到开头，但意义发生变化。
- 一个可转述句：读者愿意划线、收藏或转发。
- 一个清晰边界：知道这篇文章没有把话说满。

判断标准：

- 这句话或这个场景能不能只属于这篇文章？
- 它是否来自文章的核心观察，而不是硬编出来的漂亮句子？
- 删掉它后，文章是否明显变普通？

## 四、开头专项打磨

开头的任务不是“介绍主题”，而是把读者带进一个问题、一种处境或一个判断。具体执行按 `opening-design-protocol.md`；本节只定义高完成度文章对开头的要求。

优先使用：

- 一个小场景：具体动作、时间、物件、对话或沉默。
- 一个真问题：读者真的会在心里问的问题。
- 一个克制判断：先给判断，但立刻说明范围。
- 一个反常细节：不猎奇，但能打开文章。
- 一个选择瞬间：人物或读者正处在选择里。

避免：

- “随着……发展”“在当今社会”“众所周知”。
- “后台有人问”“群里有人问”“每到这个时候网上有人问”等虚拟来源套话。
- 一上来定义概念。
- 一上来堆数据。
- 一上来喊价值观。
- 用一个和正文关系不大的故事骗读者进入。

## 五、结尾专项打磨

结尾不是把前文再总结一次。结尾要让文章停得住。

可选结尾：

- 回环式：回到开头的场景，但读者理解已变化。
- 动作式：落在一个具体动作上。
- 判断式：给出一句克制但清楚的判断。
- 留白式：不说满，让读者自己补上最后一步。
- 远景式：把问题轻轻推到更长时间尺度。
- 行动式：给读者一个不夸张、可执行的下一步。

避免：

- “希望每个人都能……”式机械祝福。
- “总之/综上所述”式重复总结。
- 突然升华到宏大价值。
- 把复杂问题收成一句口号。

## 六、审美编辑

去 AI 味之后，再做一轮审美编辑。目标不是让文字更华丽、更像文学作品，而是让文章更清楚、更有质感、更容易被记住。

检查：

- 有没有一句真正值得留下的句子？
- 有没有一个具体场景或意象能撑住全文？
- 有没有太直白的道理可以改成动作、场景或选择？
- 有没有抽象词可以换成具体对象？
- 有没有段落节奏过于均匀？
- 有没有过度解释，导致余味消失？
- 有没有漂亮但没用的句子应该删掉？
- 有没有把情绪写成口号，而不是写成处境？
- 有没有因为追求文采而降低了清晰度、信息量和可读性？

审美编辑的原则：删掉装饰性的漂亮，保留有判断的具体；保留普通读者愿意继续读下去的清楚。

## 七、反平庸检查

交稿前用以下问题审一遍：

| 维度 | 问题 |
|---|---|
| 独特性 | 这篇文章换个人也能写出来吗？ |
| 深度 | 它有没有说出表面观点下面的东西？ |
| 具体性 | 有没有不可替代的细节、场景或判断？ |
| 力量感 | 文章有没有自己的主张，而不只是温和正确？ |
| 情绪 | 是否有真实情绪，但没有滥情？ |
| 结构 | 是否有推进、转折、对照或回环？ |
| 记忆点 | 读者能不能带走一句话、一个画面或一个判断？ |
| 完成度 | 标题、开头、正文、结尾是否互相成全？ |
| 可读性 | 普通目标读者是否愿意读完，而不是觉得文章太端、太飘或太文学？ |

如果多数答案是否定的，不要只润色句子，应回到主题升维、结构和记忆点重新设计。

## 八、多方向提示

默认不强制写多个完整版本，但在大纲阶段可以给用户一个短提示，让用户选择文章气质。

可选方向：

- 稳妥清晰版：更适合解释、指南、SEO 和普适发布。
- 观点锋利版：主张更强，适合知乎、公众号评论和个人 IP。
- 故事感更强版：更适合关系、人物、成长和生活类。
- 平台传播版：更强调开头、节奏、收藏点和转发理由。
- 高完成度深度版：更重视主题升维、结构回环、记忆点和余味。

提示要短，不要让用户负担变重。用户没有选择时，默认采用最适合平台和体裁的方向。

无论选择哪个方向，都不能让文章脱离平台读者。所谓“深度版”也必须清楚、具体、好读，不写成文学评论或散文作品。

## 九、输出要求

在大纲前输出或内部确认：

```markdown
## 高完成度增强
- 主题升维：
- 核心记忆点：
- 推荐开头方式：
- 推荐结尾方式：
- 文章气质：
- 需要避免的平庸写法：
- 可选方向提示：
```

如果用户要求直接出稿，也必须在内部完成这一步。不要为了展示流程而让文章显得笨重。

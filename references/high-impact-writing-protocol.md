# 高完成度文章增强规范

## 目标

本规范借高完成度文章的编辑视角改善清晰度、力量和完成度，但不默认追求文学性、主题升维或金句。先完成读者任务，再决定增强到哪一层。

高完成度首先意味着：文章说清了一件值得读者花时间的事，材料与判断相称，标题、开头、正文和结尾彼此兑现。

## 一、三个增强级别

### 1. 基础发布

适合查询、指南、通知、FAQ、轻内容，以及方向明确的普通平台文章。

- 说清问题、答案、来源、边界或步骤。
- 修正标题、开头、结构和明显 AI 腔。
- 不需要升维，不强制记忆点、回环、反常表达或余味。

### 2. 编辑增强

适合公众号、知乎、博客、品牌内容和需要更好阅读体验的常规文章，也是多数重要发布的默认选择。

- 改善材料取舍、段落推进、开头进入速度和结尾力度。
- 确保读者能带走一个答案、标准、动作、画面或判断。
- 可以有记忆点，但不要求生造金句或陌生概念。

### 3. 深度增强

适合用户明确要求深度、观点力度或高完成度，而且材料能够支撑的文章。

- 可以探索更深关系、长期影响、反方、代价或主题升维。
- 可以设计结构回环、核心意象或可转述判断。
- 深度必须增加理解，不得把普通问题拔高成时代、命运或人性口号。

平台发布、观点题材和故事题材本身都不是深度增强的充分条件。选择深度增强时，要在内部写明它给读者增加了什么。

## 二、增强级别判断

按顺序判断：

1. 基础发布能否完整完成读者任务？
2. 编辑增强是否能明显改善理解、阅读或行动？
3. 深度增强是否有额外材料支撑，而不是只靠抽象推演？
4. 增强后的理解成本是否仍适合目标平台和普通读者？

前一层已经足够时停止。不要把“能继续分析”误认为“必须继续分析”。

## 三、读者带走项

每篇文章至少明确一种读者带走项，不等于每篇都要有“记忆钉子”：

- 查询文章：一个准确答案或时点。
- 指南文章：一个动作、标准或检查清单。
- 决策文章：一条选择边界或代价。
- 观点文章：一个有依据的判断。
- 情感生活文章：一个被说清的处境或可尝试动作。
- 故事人物文章：一个变化、选择或后果。
- 深度文章：一个新的关系、尺度或可转述观察。

基础发布只需完成读者带走项。编辑增强和深度增强才进一步判断是否需要特殊表达设计。

## 四、主题升维的启动条件

只有同时满足以下条件才做主题升维：

- 用户或编辑路由选择深度增强。
- 表层问题下面确有材料支持的关系、选择、代价或长期影响。
- 升维后能帮助目标读者理解当前问题。
- 不需要依赖宏大词和陌生概念才能成立。

如果只是给文章换一个更抽象的说法，或者读者更关心答案、步骤和风险，则不需要升维。

可探索的方向包括：

| 表层内容 | 可探索的问题 |
|---|---|
| 事件 | 谁受到影响，改变了什么选择或代价？ |
| 方法 | 它解决了哪个真实阻力？ |
| 经验 | 在什么条件下可以迁移，在哪里失效？ |
| 情绪 | 哪个具体需要没有被看见？ |
| 热点 | 热点过去后还有什么后果？ |
| 产品/工具 | 它具体改变了谁的动作、时间或责任？ |
| 关系/生活 | 哪个互动正在让关系变好或变坏？ |

## 五、记忆点按需设计

编辑增强或深度增强可以设计记忆点。它应来自材料和文章任务：

- 一个准确判断。
- 一个真实动作、物件、场景或变化。
- 一个有用的判断标准。
- 一个正文已经走过的反例或边界。
- 一个确实发生意义变化的前后照应。

不强制使用反常表达、金句、比喻、回环或单句成段。删除所谓记忆点后文章更清楚且价值不减时，直接删除。

## 六、开头与结尾

开头按 `opening-design-protocol.md` 选择读者进入成本最低、能自然承接正文的方式。新鲜度是辅助标准，不排在清楚、可信和贴题之前。

结尾完成当前文章任务即可：

- 查询和指南可以停在下一步、检查项或适用边界。
- 观点可以停在克制判断或尚未解决的问题。
- 故事可以停在人物动作、变化或后果。
- 深度文章只有在正文持续处理过更长尺度时，才回到远景或主题。

不机械总结，不突然升华，不为了余味隐藏关键答案。

## 七、审美编辑

选择编辑增强或深度增强时增加一轮审美编辑：

- 删掉漂亮但没有增加事实、判断、情绪或阅读体验的句子。
- 检查抽象词能否还原成对象、动作、代价和结果。
- 检查文章是否每段都用一句“金句”收尾。
- 检查结构是否过分整齐，或为了不整齐加入无关闲笔。
- 检查文采是否提高了理解效率，而不是让作者显得更会写。
- 保护原稿中自然、具体、有个人取舍的部分，不把它们统一润色成标准答案。

## 八、反平庸检查

反平庸不等于反常识。按增强级别检查：

| 维度 | 问题 |
|---|---|
| 读者价值 | 读者为什么值得花时间看？ |
| 材料 | 文章是否有当前主题独有的事实、动作、例子或推理？ |
| 取舍 | 是否选择了重点，而不是面面俱到？ |
| 判断 | 观点是否有依据和边界？ |
| 推进 | 后一段是否增加了新东西？ |
| 可读性 | 普通目标读者是否读得懂、愿意继续？ |
| 完成度 | 标题承诺是否在正文得到兑现？ |

只有深度增强才额外检查主题升维、结构回环和特殊记忆点。不要用深度增强的标准惩罚一篇完成得很好的直给文章。

## 九、内部输出

```markdown
## 高完成度增强
- 增强级别：基础发布 / 编辑增强 / 深度增强
- 选择理由：
- 读者带走项：
- 是否需要升维：
- 是否需要特殊记忆点：
- 开头任务：
- 结尾任务：
- 需要保护的自然表达：
- 需要删除的表演性表达：
```

如果用户只要最终稿，不展示这张内部卡。增强规则服务文章，不增加用户流程负担。

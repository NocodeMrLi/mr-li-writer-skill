# 去 AI 味写作规范

## 优先级

去 AI 味是本 skill 的最高内容优先级。SEO、关键词、标题运营、平台结构和排版都必须服务于真实阅读体验，不能反过来把文章压成模板。

去 AI 味不是：

- 故意加入错别字、碎片句或无关闲笔。
- 把每段都写得像聊天。
- 机械删除某些词。
- 虚构“我亲身经历”“我采访过”“我翻了三份报告”。
- 为了躲避检测而强行打散所有结构。

去 AI 味是：作者有明确判断，材料有具体细节，因果关系说得清楚，语言有节奏，且不假装拥有不存在的经验。

## 一、写作前建立声音边界

先记录：

- 作者身份：用户本人、机构账号、匿名编辑或中性说明。
- 可以使用的真实经历、案例和观察。
- 不可以虚构的经历、身份、采访和数据。
- 文章允许的情绪强度和专业程度。

没有真实来源时，使用“材料显示”“公开资料显示”“这个判断的依据是……”等诚实表达，不强行使用“我”。

## 二、让文章具体

- 用场景、动作、时间、对象和结果替代抽象形容词。
- 每个重要观点至少配一个具体事实、案例、反例或推理过程。
- 给判断补边界：适用于谁、什么情况下不成立、证据到哪一步为止。
- 保留必要的重复。真人不会为了避免重复而不断换同义词。
- 让段落长短有变化，但不要为了“不整齐”加入与主题无关的内容。

## 三、保持自然结构

- 根据文章任务选择结构，不强行套五段式。
- 小标题应该服务于阅读导航，不要为了制造人味而故意写成口号。
- 事实密集的段落可以简洁，观点段落可以展开，但不要每一段都使用相同的“观点 + 数据 + 总结”。
- 开头可以是场景、问题、结论或事实，取决于内容模式和读者需求。
- 结尾应完成文章任务：给建议、回扣问题、留下判断或明确下一步，不强行升华。

## 四、中文 AI 腔检查

### 高频套话

发现以下表达时，结合上下文改写，不要做无脑替换：

- 首先、其次、再次、最后
- 总而言之、综上所述、由此可见、不难发现、值得注意的是
- 在当今……时代/背景下
- 随着……不断发展/普及/深入
- 众所周知、不得不说
- 希望对你有所帮助、让我们一起、未来可期、拭目以待

### 空洞大词

除非是真正的行业术语，否则谨慎使用：

- 赋能、抓手、闭环、链路、颗粒度、组合拳、护城河
- 深度赋能、全面升级、重磅来袭、强势登陆
- 具有重要意义、发挥重要作用、产生深远影响
- 标志着……的新篇章/里程碑

### 机械模式

- 连续多段使用“此外/同时/另外”开头。
- 每个小标题都是四字名词。
- 每段都出现“这说明”“因此我们可以看到”。
- 连续使用“不仅……更……”和“从……到……再到……”。
- 机械凑三个要点、三个数字或三个例子。
- 满屏加粗、emoji 或口号。

## 五、两轮编辑

### 第一轮：删模板

1. 搜索套话和空洞大词，逐句判断是否真的需要。
2. 删除无来源的第一人称、伪采访和泛化经历。
3. 找出连续使用的相同句式、段式和转折词。
4. 把“结论 + 空泛解释”改成“事实/场景 + 推理 + 判断”。
5. 检查标题和正文是否兑现同一个承诺。

### 第二轮：恢复人声

1. 朗读每段，删掉不像自然表达的句子。
2. 把抽象情绪改成可见的动作、选择或后果。
3. 保留一到两处明确态度，但为态度补证据或适用边界。
4. 检查不同段落的节奏，不追求每段长度一致。
5. 检查文章是否仍然清楚、可信、可执行。

## 六、AI 味自评

从 0-10 评估，超过 3 分必须重写。只把以下问题作为信号，不把分数当成科学检测结果：

| 问题 | 参考扣分 |
|---|---:|
| 套话或空洞大词过多 | 1 |
| 出现虚构第一人称或伪经历 | 2 |
| 段落、标题和论证结构高度重复 | 1 |
| 缺少具体事实、场景、反例或边界 | 1 |
| 文章像搜索摘要或新闻通稿 | 1 |
| 为了关键词牺牲自然语序 | 1 |
| 结尾空泛升华或机械互动 | 1 |
| 情绪和观点全部中性，没有作者判断 | 1 |
| 为了“像真人”出现无关闲笔或刻意口语 | 1 |

最终目标不是“检测器低分”，而是让真实读者读完后觉得：这篇文章有人认真想过，也诚实知道自己不知道什么。

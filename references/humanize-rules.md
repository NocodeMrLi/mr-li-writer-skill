# 去AI化写作规则

目标：让文章读起来像一个有观点、有情绪的真人写的，而不是模型生成的。写作时主动遵守，完稿后对照本清单自查改写一遍。

## 一、注入人味（正向要做的事）

- **有观点**：不只罗列事实，要对事实表态。"这个政策表面上是放宽，实际上门槛抬高了"比"该政策引起广泛关注"更像人话。
- **节奏变化**：长短句混用。短句砸重点。然后接一句展开的，把来龙去脉讲清楚。
- **承认复杂**：真实的人有混合情绪。"这个数据挺亮眼，但我总觉得哪里不对"比单向度的赞美可信。
- **适当用"我/我们"**：第一人称不是不专业，是诚实。"我翻了最近三年的数据"比"通过分析近三年数据"更自然。
- **允许不完美**：偶尔带个口语化的补充、一个设问，比严丝合缝的结构更像真人。
- **具体的情绪**：不写"令人担忧"，写"凌晨两点还在改方案的人，看到这条新闻估计睡不着"。

## 二、中文 AI 腔黑名单（发现必改）

### 连接词与套话
- 首先/其次/再次/最后（连续使用时）
- 总而言之、综上所述、由此可见、不难发现、值得注意的是、毋庸置疑
- 随着……的不断发展/普及/深入
- 在当今……时代/背景下
- 众所周知、不得不说

### 空洞大词
- 赋能、抓手、闭环、链路、颗粒度、组合拳、护城河（除非真的是行业语境）
- 深度赋能、全面升级、重磅来袭、强势登陆
- 具有重要意义、发挥重要作用、产生深远影响
- 标志着……的新篇章/里程碑

### 机械结构
- "不仅……更……" 连用
- "从……到……再到……" 的假跨度
- 凡事凑三点："速度快、成本低、效果好"
- "加粗标题：解释" 的机械列表（如 - **用户体验：** 得到了提升）
- 段落开头清一色"此外""同时""另外"

### 讨好与客套
- "希望对你有所帮助""如果觉得有用，欢迎点赞收藏"
- "让我们一起……" 式结尾
- 空洞的正能量结尾："未来可期""前景广阔""拭目以待"

### 免责声明残留
- "截至我的知识更新时间"
- "由于信息有限，无法确定"
- 证据不足时直接说"目前没有公开数据"，不要写 AI 味的免责声明

### 开头与结构陷阱（最容易被一眼识破的 AI 指纹）
- 第一段以"根据/数据显示/报告显示"开头
- 第一段直接抛出核心结论或判断（结论前置、砸下来）
- 第一段堆 3 个以上数字（数据轰炸）
- 全文严格切成"开头/事实/分析/行动/结尾"五段式，且各部分字数配比均匀
- 小标题字数、句式整齐划一（齐刷刷的工整感）
- 每个观点都配一模一样的"数据+案例"对称结构（均质感）

## 三、语言细节

- **少用破折号**（——），中文真人写作中低频出现，改用逗号、句号
- **少用 emoji**，正文中原则上不用；排版装饰也保持克制
- **别乱加粗**：加粗只给真正的关键数字和结论，满屏加粗是典型的 AI 排版痕迹
- **同义词回避**：同一个概念前后用同一个词，不要为了"避免重复"来回换说法（真人写作恰恰有自然的重复）
- **直接引用用直角引号或中文引号**，全文统一

## 四、中英文高频 AI 词汇（替换示例）

| AI 腔 | 真人写法 |
|-------|----------|
| 进行深入分析 | 拆开看 / 具体分析 |
| 提供有力支撑 | 撑起了 / 靠的是 |
| 显著提升 | 涨了三成 / 明显快了 |
| 引发广泛关注 | 不少人都在讨论 |
| 奠定了坚实基础 | 打下了底子 / 从这儿起步 |
| 充分彰显了 | 说明了 / 看得出 |

## 五、自查流程

完稿后执行：
1. 全文搜索本文件"黑名单"中的词，逐处改写或删除
2. 朗读每一段，凡是"像新闻通稿/像报告"的句子重写
3. 检查是否每个小节都有具体信息（数字、案例、场景），删掉只有形容词没有事实的段落
4. 检查节奏：连续 3 句以上长度相近就打断重组
5. **开头检查（最关键）**：第一段是不是在"讲故事/抛疑问/给体感"？如果是"报数据/下结论/甩报告"，整段重写
6. **结构检查**：小标题是否长短不一、有口语有反问？是否存在"每个观点都对称配数据"的均质感？有的话打破它；是否存在"五段式配比均匀"的工整感？打散
7. **情感检查**：找出至少两处"只有形容词没有画面"的抽象句，改成具体场景或带温度的主观判断；确认全文有 1-2 处明显的个人态度锋芒

## 六、AI 味快速自评（交稿前打一次分）

参考"AI味检测"思路，从 0-10 给文章打个分，**超过 3 分就回去改**：

| 扣分项 | 一次扣 1 分 |
|--------|------------|
| 出现黑名单词汇（赋能/抓手/综上所述/值得注意的是…） | |
| 第一段以"根据/数据显示/报告显示"开头，或核心结论前置 | |
| 第一段堆 3 个以上数字（数据轰炸） | |
| 全文五段式配比均匀、小标题整齐划一（高度规整） | |
| 通篇情绪平均、无起伏、无主观锋芒（情感色彩弱） | |
| 连续 3 段以上开头都是"此外/同时/另外" | |
| 满屏加粗或机械"加粗标题：解释"列表 | |
| 段落长度高度一致、无短句砸点 | |
| 结尾是"未来可期/让我们拭目以待"式空洞升华 | |
| 出现破折号堆砌、emoji 装饰标题 | |
| 通篇无人称、无观点、像维基百科 | |

目标：AI 味评分 ≤ 3。分数低不代表写得好，但分数高一定像机器写的。

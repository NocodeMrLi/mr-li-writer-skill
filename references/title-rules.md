# SEO 与内容运营标题策划规范

## 总原则

标题不是“让模型多生成几个句子”，而是一次小型的内容运营决策。必须先判断用户为什么会搜、为什么会点、点进来想得到什么，再设计标题。

标题要同时完成四件事：

1. 让搜索引擎理解主题。
2. 让目标读者识别“这和我有关”。
3. 让读者知道文章会解决什么问题。
4. 让正文有足够空间兑现承诺。

不要把“爆款”当成唯一目标。对长期内容，准确、可检索、可复用、可信，通常比短期刺激更重要。

## 第一步：建立标题策略卡

生成任何候选标题前，先在内部填写：

| 字段 | 要回答的问题 |
|---|---|
| 内容主题 | 这篇文章具体讨论什么？ |
| 主搜索词 | 用户最可能输入的核心词是什么？ |
| 次级搜索词 | 哪些同义词、长尾问题和场景词值得覆盖？ |
| 搜索意图 | 信息了解、比较选择、执行操作、购买决策，还是平台浏览？ |
| 用户阶段 | 刚发现问题、正在研究、准备执行，还是已经在选择？ |
| 目标读者 | 谁会点击？他们最在意风险、收益、时间还是判断？ |
| 内容承诺 | 读者看完能得到什么具体结果？ |
| 差异化证据 | 本文有什么材料、案例、数据或观点不是常见摘要能替代的？ |
| 平台约束 | 搜索标题、H1、公众号标题、知乎标题、小红书标题是否需要区分？ |
| 禁用承诺 | 哪些数字、结果或表述目前没有证据，不能写进标题？ |

没有真实关键词工具数据时，不得编造“月搜索量”“竞争度”“排名概率”。可以使用搜索联想、相关问题、已有标题、用户原话和内容主题做定性判断，并明确标注“推断”。

## 第二步：判断标题任务类型

根据目标选择 1-2 个主类型，不要每种类型都批量套用。

- **搜索解答型**：核心词 + 用户问题/明确结果。适合长期 SEO。
- **清单步骤型**：核心词 + 人数/步骤/时间范围。适合实用指南。
- **比较决策型**：A 与 B + 选择标准/适合人群。适合决策阶段。
- **避坑风险型**：核心词 + 常见错误/风险/边界。必须有真实证据。
- **观点冲突型**：常见看法 + 本文修正。必须在正文解释冲突。
- **案例故事型**：具体对象/场景 + 变化或问题。不得虚构案例。
- **平台分发型**：一句自然的人话 + 读者情绪或身份。不能牺牲主题识别度。

## 第三步：设计关键词位置

- 主搜索词优先出现在标题前半段，但不要为了关键词破坏语序。
- 次级关键词可以放在副标题、Meta Description、导语和小标题中。
- 同一标题不要堆 3 个以上关键词。
- 不要把品牌词、人名或机构名一概视为禁词。是否出现由实体/隐私模式和文章任务决定。
- 关键词只是帮助理解主题，不是标题的全部。

## 第四步：控制标题承诺

标题中的每个可验证元素都必须能在正文找到依据：

- 数字必须有明确口径。
- 时间、价格、政策和资格条件必须对应当前有效来源。
- “适合谁”“如何选择”“有什么变化”必须在正文给出判断。
- “最”“唯一”“必然”“翻倍”“保证”等绝对词，除非有充分证据，否则禁用。
- 不使用“震惊”“不看后悔”“速看”“全网疯传”等低信息量刺激词。

## 第五步：候选生成方式

只在完成策略卡后生成 6-10 个候选，按用途分组：

1. 1-2 个 SEO 主标题。
2. 2-3 个搜索意图明确的实用标题。
3. 2-3 个差异化/观点标题。
4. 1-2 个平台分发标题。

每个候选必须附带：

```text
标题：
用途：
主关键词：
搜索/阅读意图：
标题承诺：
正文证据：
主要风险：
推荐度：
```

## 第六步：相对评分

使用相对评分，不要把主观判断伪装成预测点击率。总分 100：

| 维度 | 权重 | 判断标准 |
|---|---:|---|
| 搜索相关性 | 25 | 是否覆盖主问题和核心词 |
| 承诺清晰度 | 20 | 读者是否知道能得到什么 |
| 目标人群匹配 | 15 | 是否准确击中读者阶段和痛点 |
| 差异化 | 15 | 是否有证据支撑的独特角度 |
| 可信度 | 15 | 是否避免夸张、虚构和无法兑现 |
| 平台适配 | 10 | 是否符合标题长度、语气和展示场景 |

评分低于 75 的候选不作为首选。评分只是内部排序依据，不能表述为“预测点击率”。

```text

   - 评分：
   - 推荐理由：

   - 适用：正文页面
   - 与 SEO Title 的差异：

3. 社交分发标题：
   - 适用：公众号/知乎/小红书
   - 触发点：

## 备选标题
...

## SEO 元数据

```

SEO Title、正文 H1 和社交分发标题可以不同。不要为了形式统一而让一个标题同时承担所有任务。

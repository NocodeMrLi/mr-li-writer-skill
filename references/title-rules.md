# 爆款标题创作规则

## 硬性约束

- **30 字以内**（含标点）
- **含核心关键词**：把用户会搜的词放进标题（如"PMP""软考""报名""2026"），SEO 友好
- **直白优先**：读者扫一眼就知道这篇讲什么、跟我有什么关系
- **痛点 + 痒点**：痛点 = 怕错过/怕考不过/怕白花钱；痒点 = 拿证/涨薪/评职称/省时间

## 创作角度（每个标题选 1-2 个角度组合）

1. **时间紧迫型**："7 月截止""最后 X 个月""再不报名就晚了"
2. **利益直给型**："考完直接评职称""一个证顶三个用"
3. **数字清单型**："3 个变化""5 类人适合考"
4. **避坑警示型**："别白考""90% 的人报错科目"
5. **悬念反差型**："通过率最低的一科，反而最值得考"
6. **人群圈定型**："工作 5 年的 PM，建议看看这个证"

## 输出格式

生成 5-10 个候选，按推荐度排序，每条标注：

```
1. 【推荐】标题原文 （角度：时间紧迫+利益 / 28 字）—— 推荐理由一句话
2. 标题原文 （角度：数字清单 / 22 字）—— 推荐理由一句话
...
```

- 第 1 名必须给明确推荐标星和理由
- 标注字数方便用户判断是否超 30 字
- 如果用于多平台，可分组：公众号版 / 小红书版（更口语、可加 emoji）

## 禁忌

- 不用"震惊！""不看后悔！"等已被平台限流的标题党词
- 不堆砌关键词导致读不通
- 不承诺无法兑现的内容（" guaranteed 通过"之类）
- 不含品牌名、人名

# 平台标题、点击契约与搜索策划规范

## 总原则

标题不是“让模型多生成几个句子”，而是一次小型的编辑决策。先建立点击契约：读者为什么现在会点、第一眼是否看懂、点进来能得到什么、正文凭什么兑现。

发布平台和内容目标必须分开。公众号、知乎、小红书、官网/网页、个人博客是发布平台；普通传播、GEO、SEO、转化销售、专业报告是内容目标。SEO/GEO 不作为发布平台，而是影响标题、结构、FAQ、来源和元数据的内容目标。

标题按平台和内容目标承担不同任务，不要求一个标题同时完成所有事情：

1. 让目标读者识别“这和我有关”。
2. 用熟悉的问题、场景或对象降低理解成本。
3. 提供一点足以触发点击的新信息或明确收益。
4. 让正文有足够空间兑现承诺。
5. 只有 SEO/GEO 目标需要额外保证搜索引擎理解主题。

不要把“爆款”当成唯一目标。对长期内容，准确、可检索、可复用、可信，通常比短期刺激更重要。

## 第一步：建立点击契约

生成标题前先回答：

| 字段 | 要回答的问题 |
|---|---|
| 目标读者 | 谁会看到这个标题？ |
| 此刻相关性 | 他为什么现在会关心？ |
| 熟悉入口 | 哪个问题、场景、对象或原话能让他一眼认出？ |
| 阅读动机 | 他是求答案、选择、避坑、共鸣、故事还是谈资？ |
| 内容承诺 | 看完具体能得到什么？ |
| 正文证据 | 哪段材料能够兑现承诺？ |
| 理解成本 | 是否需要先解释一个陌生概念才能看懂标题？ |
| 禁用承诺 | 哪些数字、结果和情绪强度没有依据？ |

差异化不是必选项。常见主题只要对应真实需求，也可以使用清楚、自然、可信的标题。默认采用“熟悉的问题 + 一点新信息”，不采用“陌生概念 + 作者自认为深刻的判断”。

## 第二步：补充平台与搜索策略

查询/指南型任务可以使用轻量标题流程：提取主搜索词、用户自然问法、内容承诺和禁用承诺，输出 1 个推荐标题 + 2 个备选标题；不强制完整评分矩阵。观点/故事型、SEO/GEO、转化销售和重要平台文章仍使用完整标题策略卡。

生成任何候选标题前，先在内部填写：

| 字段 | 要回答的问题 |
|---|---|
| 编辑路由结论 | 读者任务、创新档位和增强级别是什么？ |
| 内容主题 | 这篇文章具体讨论什么？ |
| 主搜索词 | 用户最可能输入的核心词是什么？ |
| 次级搜索词 | 哪些同义词、长尾问题和场景词值得覆盖？ |
| 搜索意图 | 信息了解、比较选择、执行操作、购买决策，还是平台浏览？ |
| 内容目标 | 普通传播、GEO、SEO、转化销售，还是专业报告？ |
| 用户阶段 | 刚发现问题、正在研究、准备执行，还是已经在选择？ |
| 目标读者 | 谁会点击？他们最在意风险、收益、时间还是判断？ |
| 内容承诺 | 读者看完能得到什么具体结果？ |
| 可选差异化依据 | 如果需要差异化，本文有什么材料、案例、数据或观点支持？ |
| 需避开的同质化标题 | 市面上已经被大量重复的标题套路是什么？ |
| 平台约束 | 搜索标题、H1、公众号标题、知乎标题、小红书标题是否需要区分？ |
| 禁用承诺 | 哪些数字、结果或表述目前没有证据，不能写进标题？ |

没有真实关键词工具数据时，不得编造“月搜索量”“竞争度”“排名概率”。可以使用搜索联想、相关问题、已有标题、用户原话和内容主题做定性判断，并明确标注“推断”。

## 第三步：判断标题任务类型

根据目标选择 1-2 个主类型，不要每种类型都批量套用。

- **搜索解答型**：核心词 + 用户问题/明确结果。适合长期 SEO。
- **清单步骤型**：核心词 + 人数/步骤/时间范围。适合实用指南。
- **比较决策型**：A 与 B + 选择标准/适合人群。适合决策阶段。
- **避坑风险型**：核心词 + 常见错误/风险/边界。必须有真实证据。
- **观点判断型**：读者熟悉的问题 + 本文有依据的判断。只有材料确实构成修正时才使用冲突写法。
- **案例故事型**：具体对象/场景 + 变化或问题。不得虚构案例。
- **平台分发型**：一句自然的人话 + 读者情绪或身份。不能牺牲主题识别度。
- **小红书笔记型**：身份/场景/问题 + 具体收益或避坑。必须短、具体、像用户会保存的一条笔记。

## 第四步：设计关键词位置

- 主搜索词优先出现在标题前半段，但不要为了关键词破坏语序。
- 次级关键词可以放在副标题、Meta Description、导语和小标题中。
- 同一标题不要堆 3 个以上关键词。
- 不要把品牌词、人名或机构名一概视为禁词。是否出现由实体/隐私模式和文章任务决定。
- 关键词只是帮助理解主题，不是标题的全部。

小红书标题不按 SEO 标题处理。小红书标题优先场景、身份、问题和收藏价值，例如“新手第一次选 X，先看这 5 点”。不要为了关键词完整度写成长句，也不要堆叠多个搜索词。

知乎标题优先真实问题或专栏判断。问题型标题要像真实用户会问的问题，判断型标题要在正文里给出边界、反例和适用人群。

公众号标题可以兼顾传播和识别度，但不能变成无法兑现的煽动标题。

官网/网页标题才默认进入 SEO/GEO 标题处理，并根据内容目标输出 SEO Title、H1、Meta Description、FAQ 问题和相关搜索问法。

## 第五步：控制标题承诺

标题中的每个可验证元素都必须能在正文找到依据：

- 数字必须有明确口径。
- 时间、价格、政策和资格条件必须对应当前有效来源。
- “适合谁”“如何选择”“有什么变化”必须在正文给出判断。
- “最”“唯一”“必然”“翻倍”“保证”等绝对词，除非有充分证据，否则禁用。
- 不使用“震惊”“不看后悔”“速看”“全网疯传”等低信息量刺激词。

## 第六步：候选生成方式

只在完成点击契约后生成候选。普通任务生成 3-6 个即可，重要发布或用户要求比较时生成 6-10 个。候选按当前用途选择，不凑齐所有类型：

1. 1-2 个与内容目标匹配的主标题。
2. 2-3 个搜索意图明确的实用标题。
3. 0-2 个有材料支撑的观点或视角标题；直给型任务可以没有。
4. 1-2 个平台分发标题。

发布平台为小红书时，改为生成 6-10 个小红书笔记标题候选，不输出 SEO Title 作为主结果。候选要覆盖：

- 身份场景型
- 结果/收益型
- 避坑型
- 收藏清单型
- 反常提醒型

每个候选必须附带：

```text
标题：
用途：
主关键词：
搜索/阅读意图：
标题承诺：
正文证据：
主要风险：
推荐度：
```

## 第七步：相对评分

使用相对评分，不要把主观判断伪装成预测点击率。普通传播默认总分 100：

| 维度 | 权重 | 判断标准 |
|---|---:|---|
| 此刻相关性 | 20 | 读者为什么现在会关心 |
| 承诺清晰度 | 20 | 读者是否知道能得到什么 |
| 点击动机 | 15 | 是否触发答案、选择、避坑、共鸣或故事兴趣 |
| 可信度 | 15 | 是否避免夸张、虚构和无法兑现 |
| 自然口语感 | 15 | 是否像目标平台上的真人会说，语序是否自然 |
| 平台适配 | 10 | 是否符合标题长度、语气和展示场景 |
| 创新净收益 | 5 | 新信息是否值得它增加的理解成本 |

SEO/GEO 内容把“点击动机”中的 10 分调整为“搜索相关性”；专业报告可以把“自然口语感”中的 10 分调整为“主题识别与术语准确”。评分低于 75 的候选不作为首选。评分只是内部排序依据，不能表述为“预测点击率”。

## 输出格式

```text
## 标题策略
- 读者任务：
- 此刻相关性：
- 熟悉入口：
- 阅读动机：
- 目标人群：
- 内容承诺：
- 理解成本：
- 可选差异化依据：
- SEO/GEO 目标时的主搜索词：

## 推荐方案
1. SEO Title：
   - 适用：搜索结果页
   - 关键词：
   - 承诺：
   - 评分：
   - 推荐理由：

2. H1：
   - 适用：正文页面
   - 与 SEO Title 的差异：

3. 社交分发标题：
   - 适用：公众号/知乎/小红书
   - 触发点：

## 备选标题
...

## SEO 元数据
- Meta Description：
- 摘要：
- 建议 URL slug：
- 相关问题：
```

SEO Title、正文 H1 和社交分发标题可以不同。不要为了形式统一而让一个标题同时承担所有任务。

## 小红书标题输出格式

发布平台为小红书时，使用这个输出格式：

```text
## 小红书标题策略
- 目标人群：
- 场景：
- 笔记承诺：
- 适合的标题方向：
- 需要避开的标题套路：

## 推荐标题
1. 标题：
   - 类型：身份场景 / 避坑 / 收藏清单 / 结果收益 / 反常提醒
   - 为什么适合：
   - 正文如何兑现：

## 备选标题
...
```

小红书标题必须短、具体、有场景，不写成公众号标题或 SEO 长标题。

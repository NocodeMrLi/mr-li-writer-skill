# 编辑路由与最低必要创新规范

## 目标

写作前先判断读者为什么愿意看、这篇内容靠什么站住，再决定是否需要创新。创新是服务阅读任务的手段，不是每篇文章都要完成的仪式。

默认原则是 **最低必要创新**：原方向已经清楚、有用、可信时，保留它；只有同质化会明显损害阅读价值时，才逐级增加新意。

## 一、先识别读者任务

每篇内容先选择一个主任务，可以有一个副任务：

| 读者任务 | 读者真正需要什么 | 优先能力 |
|---|---|---|
| 找答案 | 快速得到可靠结论 | 准确、直接、时效 |
| 做选择 | 看懂差异和代价 | 标准、边界、适合人群 |
| 避风险 | 知道哪里最容易出错 | 证据、提醒、行动顺序 |
| 学方法 | 能照着完成一件事 | 步骤、示例、检查清单 |
| 被理解 | 看见自己的处境被说清 | 具体、克制、共情 |
| 看故事 | 跟随人物、变化和后果 | 场景、动作、因果 |
| 找谈资 | 获得可转述的新信息 | 信息增量、表达效率 |
| 确认判断 | 判断自己的看法是否站得住 | 依据、反方、边界 |
| 获得行动动力 | 愿意迈出下一步 | 阻力识别、低门槛动作 |

如果一篇文章同时想完成四五个任务，先收窄。主任务决定结构，副任务只补充，不抢主线。

## 二、检查作品靠什么站住

动笔前确认当前材料能否支撑目标篇幅和承诺：

- 硬信息内容靠官方事实、时间、数据、流程和适用范围。
- 指南内容靠可执行步骤、判断标准、常见错误和真实限制。
- 观点内容靠事实差异、推理、反例、作者取舍和清晰边界。
- 情感生活内容靠处境、动作、关系变化和诚实判断，可以没有数据。
- 人物故事内容靠真实场景、选择、变化和后果，不用抽象道理填篇幅。
- 虚构内容靠人物目标、行动、冲突和场景变化，不伪装成现实材料。

不使用固定“五件材料”或固定字数门槛。判断标准是：计划中的主要段落能否各自得到材料或真实推理支撑。材料不足时，先研究、追问、缩小题目或缩短篇幅，不用重复解释补长度。

## 三、创新必要性闸门

先回答五个问题：

1. 原方向能否直接完成读者任务？
2. 同主题常见内容是否已经充分解决这个问题？
3. 新角度能否带来真实读者收益，而不只是显得聪明？
4. 当前材料能否兑现这个新角度？
5. 新说法带来的理解成本是否小于它提供的价值？

如果第 1 项为“能”，且第 3、4 项没有明显增益，停止升级，采用直给型或微创新型。

## 四、四档创新模式

### 1. 直给型

适合政策、报名、价格、教程、通知、事实更新和已有方向足够准确的内容。

- 不改核心立意。
- 优化信息顺序、标题清晰度、来源和行动提示。
- 不制造反常识，不添加宏大意义。

### 2. 微创新型

适合主题常见但读者仍有实际需求的内容，也是多数日常文章的默认上限。

- 保留读者熟悉的问题。
- 从案例、场景、顺序、判断标准、语言或取舍上增加一点新信息。
- 不为差异化创造陌生概念。

### 3. 视角转换型

适合同质化明显、但通过换人群或换场景能增加价值的内容。

- 可换目标人群、使用场景、时间尺度、利益关系、反方或适用边界。
- 转换后仍要让读者一眼认出原问题。
- 如果解释新角度需要大段铺垫，退回微创新型。

### 4. 概念创新型

只适合材料充分、确实存在新观察，而且新概念能帮助读者理解和转述的少数文章。

- 概念必须有事实、案例或完整推理支撑。
- 能用普通话说清楚，不靠陌生词制造高级感。
- 删除概念后文章更清楚且价值不减时，删除概念。
- 不把每篇文章都推到这一档。

## 五、创新收益判断

内部比较候选方向时，不追求总分最大，只判断是否值得增加复杂度：

| 维度 | 要回答的问题 |
|---|---|
| 读者收益 | 是否更快获得答案、判断、方法、理解或体验？ |
| 此刻相关性 | 为什么读者现在会关心？ |
| 材料支撑 | 新角度是否有真实材料兑现？ |
| 理解成本 | 是否需要先学一个陌生概念才能看懂？ |
| 原意保真 | 是否仍然保留用户最想说的东西？ |
| 平台适配 | 是否符合当前平台的阅读动作？ |

只有读者收益和材料支撑明显增加，且理解成本可接受时，才升级创新档位。

## 六、同主题变体

同一主题再次写作时，不靠随机换词制造差异。从以下变量中选择真正与本次任务有关的变化：

- 读者状态不同：刚发现、正在比较、准备行动、已经失败。
- 材料中心不同：事实、人物、过程、反例、选择或后果。
- 平台动作不同：搜索求解、连续阅读、收藏、讨论或转化。
- 说话位置不同：解释者、实践者、观察者、编辑或中性说明。
- 内容任务不同：回答、判断、陪伴、叙事或行动。

独立宿主和模型之间可能没有历史记忆，不承诺永久记住旧开头。每次任务仍必须根据当前材料重新选择入口，不能默认复用最常见的反常识、虚拟提问或场景套路。

## 七、内部路由卡

正式大纲前内部确认：

```markdown
## 编辑路由
- 读者主任务：
- 读者此刻状态：
- 作品靠什么站住：
- 材料是否足够：
- 创新档位：直给型 / 微创新型 / 视角转换型 / 概念创新型
- 采用该档位的读者收益：
- 需要避免的理解成本：
- 是否需要执行完整选题诊断：
- 增强级别：基础发布 / 编辑增强 / 深度增强
```

如果用户只要最终稿，这张卡不对外展示。它用于约束决策，不是新的交付负担。

## 八、禁止事项

- 不把“有新意”排在“有人愿意看”之前。
- 不因题目常见就否定真实需求。
- 不为了创新强行反主流、造概念、换陌生说法或拔高主题。
- 不把所有观点文章自动判为需要立意升级。
- 不把所有平台文章自动判为需要深度增强。
- 不用固定结构、固定金句或固定开头证明文章经过设计。
